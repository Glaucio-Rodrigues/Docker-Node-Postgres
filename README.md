# 🚀 API RESTful - Gestão de Utilizadores

Aplicação backend desenvolvida para gestão de utilizadores com foco em boas práticas de arquitetura, organização de rotas e integração com banco de dados relacional.

## 🛠️ Tecnologias Utilizadas

- **Node.js & Express** — Construção da API e estrutura de rotas/controllers
- **Docker** — Containerização do PostgreSQL para ambiente isolado
- **Sequelize ORM & CLI** — Mapeamento objeto-relacional e versionamento via Migrations
- **PostgreSQL** — Banco de dados relacional
